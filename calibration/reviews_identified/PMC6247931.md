### 1. SUMMARY AND OVERALL IMPACT STATEMENT

Hadfield et al. present an Application Note describing Nextstrain (`nextstrain.org`), an open-source bioinformatics pipeline and interactive web visualization platform for real-time phylodynamic tracking of viral pathogens (including seasonal and avian influenza, Ebola, Zika, and dengue). The architecture couples automated sequence and metadata ingestion from NCBI, GISAID, ViPR, and GitHub with maximum-likelihood phylogenetic inference, molecular-clock dating, and discrete-trait ancestral state reconstruction via TreeTime (Sagulenko et al., 2018), rendering linked phylogenetic, geographic, and site-wise Shannon entropy panels in the browser. The authors report that the pipeline completes a full phylodynamic build of the West African Ebola epidemic ($n = 1,581$ genomes) in under 2 hours on a modern laptop, while providing open Python and JavaScript source code (`[GITHUB_REPO_REDACTED]`) and protecting raw sequence redistribution to encourage rapid data sharing.

As a software and infrastructure contribution, Nextstrain is well engineered, openly documented, and addresses a genuine bottleneck in real-time genomic epidemiology. Because this is a short Application Note rather than an empirical research article, its methodological limitations stem primarily from how statistical uncertainty and sampling bias are surfaced to end users in the visualization interface: (1) maximum-likelihood discrete-trait geographic reconstruction in TreeTime treats sampling counts per deme as proportional to transition opportunities unless explicitly subsampled, and rendering single point-estimate "most likely transmission events" as animated map arrows can mislead public health users when geographic ascertainment is skewed; (2) branch-length and ancestral node-date confidence intervals from TreeTime are not visually represented on the default time-tree layout; and (3) no quantitative benchmark table (e.g., runtime, memory scaling, and date/trait accuracy across the supported viral builds) is provided in the note to substantiate the performance claims.

### 2. SPECIFIC CONCLUSIONS AND ASSESSMENT OF SUPPORT

* **Nextstrain provides an open-source, modular phylodynamic pipeline and synchronized browser interface capable of processing outbreak-scale viral datasets ($n = 1,581$ Ebola genomes) in under 2 hours:** **[Well Supported].**  
  The separation of core phylodynamic tasks (alignment, tree building, TreeTime clock/ancestral reconstruction, and JSON export) from pathogen-specific configuration layers is verifiable in the public GitHub repositories, and the $<2\text{ h}$ runtime for 1,581 sequences reflects the $O(N)$ scaling of TreeTime's dynamic programming routines.

* **Site-wise Shannon entropy bars and branch-level mutation reconstructions enable rapid visual monitoring of segregating and putatively adaptive variants across phylogeny and geography:** **[Well Supported].**  
  The linked entropy panel and branch hover states directly map reconstructed amino acid and nucleotide substitutions onto the time tree and geographic map, as demonstrated for Zika (Fig. 1) and avian influenza A/H7N9.

* **Maximum-likelihood ancestral state reconstruction of discrete geographic traits in Nextstrain identifies "probable transmission events" between regions:** **[Fragile].**  
  In Section 2 (lines 67 and 80), the authors state that discrete-trait reconstruction allows "identification of probable transmission events given the sampled data," with shifts drawn as links on the map and confidence conveyed via color saturation. However, maximum-likelihood discrete-trait ("mugration") models are notoriously sensitive to spatiotemporal sampling heterogeneity: an unsampled or undersampled source hub will be systematically inferred as a sink or bypassed entirely, and high marginal posterior/likelihood saturation at an internal node under an unstratified CTMC model often reflects local sampling density rather than true epidemiological directionality. While the authors briefly acknowledge that "sampling bias and lack of data can obscure transmission links," drawing animated directed transmission arrows between countries overstates the causal resolution of unadjusted discrete-trait models.

* **Withholding raw genome sequences while disseminating derived trees and metadata resolves data-sharing hesitancy without compromising reproducibility:** **[Moderately Supported].**  
  Preventing raw FASTA downloads satisfies restrictive database terms (such as GISAID) and facilitates rapid display, but it prevents third-party users from directly auditing alignment quality, recombination, or subsampling sensitivity from the web export alone unless they separately obtain raw sequences from the primary repositories.

### 3. CONSTRUCTIVE AND DOABLE SUGGESTIONS FOR IMPROVEMENT

#### 1. Add Quantitative Subsampling Diagnostics and Sampling-Bias Warnings to Discrete-Trait Map Transmissions
* **WHY:** When sequence counts across countries or states are unaligned with actual disease incidence, TreeTime's discrete-trait continuous-time Markov chain (CTMC) infers transition rates driven by sample volume, producing high-saturation internal node states that reflect ascertainment bias rather than transmission history.
* **WHAT:** Incorporate an automated deme-balance diagnostic into the pipeline and replace single directed transmission arrows on the map when ancestral state entropy exceeds a threshold or when subsampling sensitivity is high.
* **HOW:** In the Python build scripts (`augur`), compute the ratio of sequence count to reported case incidence (where available) or run $K = 5$ bootstrap subsampling replicates across demes; in the JavaScript front end (`auspice`), suppress directed map arcs or render them as dashed/uncertain whenever the ancestral or descendant node state probability falls below 0.70 across subsampling replicates.

#### 2. Display Temporal Confidence Intervals on Internal Nodes in the Time-Tree View
* **WHY:** Section 2 describes conveying discrete-trait confidence through color saturation and hover tooltips, but molecular-clock dating in early outbreaks with low sequence diversity carries substantial temporal uncertainty (wide confidence intervals around internal node dates) that can alter interpretations of introduction timing when users scrub the interactive time slider.
* **WHAT:** Expose TreeTime's marginal node-date confidence intervals (`--confidence`) directly in the visual tree layout.
* **HOW:** Export the 95% marginal date bounds (`num_date_confidence`) from TreeTime into the Auspice JSON schema and render horizontal error bars on internal nodes when hovering or toggling a "Date uncertainty" checkbox in the tree panel.

#### 3. Provide a Quantitative Performance and Dataset Summary Table
* **WHY:** The manuscript mentions a single runtime number ($n = 1,581$ Ebola genomes in under 2 hours) in the text without specifying hardware details, tree-building software (e.g., IQ-TREE, RAxML, or FastTree), or scaling metrics for the other live builds mentioned (Zika, seasonal influenza, avian H7N9, dengue).
* **WHAT:** Add a concise 1-table benchmark summarizing each live Nextstrain pathogen build.
* **HOW:** Tabulate for Ebola, Zika, Influenza (H3N2), Avian H7N9, and Dengue: (i) total database genomes, (ii) subsampled build size ($N$), (iii) genome length ($L$), (iv) wall-clock runtime and peak RAM broken down by alignment, tree inference, and TreeTime dating/ancestral reconstruction on a specified CPU architecture.

#### 4. Temper Language Around "Probable Transmission Events"
* **WHY:** Phylogeographic state transitions along branches of a subsampled viral phylogeny represent lineage migration transitions between coarse administrative regions, not direct epidemiological transmission events.
* **WHAT & HOW:** In lines 67 and 80, replace `"identification of probable transmission events"` and `"inference of the most likely transmission events"` with `"inference of ancestral geographic lineage transitions"` to avoid conflating coarse phylogeographic state changes with direct host-to-host or deme-to-deme transmission chains.
