### 1. SUMMARY AND OVERALL IMPACT STATEMENT

Ran and Brubaker present `scCD45RA`, a Python package (`github.com/BrubakerLab/ScCD45RA`) that predicts binary CD45RA surface protein expression status ($\text{CD45RA}^+$ vs. $\text{CD45RA}^-$) in human T cells from conventional short-read 3'/5' scRNA-seq count matrices. Using CITE-seq healthy adult PBMC data (GSE144434, $N = 5,559$ cells filtered for $\text{CD19}^-\text{CD3}^+$ T cells), the authors binarize ADT CD45RA protein levels via Otsu's threshold $t^*$ after discarding ambiguous intermediate cells within $[t^* - 0.5, t^* + 0.5]$. They select input features by combining Monocle 3 quasi-Poisson differentially expressed genes ($|\log_2 \text{FC}| \ge t_{\text{DE}}$) with genes correlated with the splicing factor `hnRNPLL` (top percentile $P_{\text{hn}}$), and train six classifiers (Logistic Regression, linear SVM, RBF SVM, Stacked LR+SVM, and two MLPs) using Bayesian hyperparameter optimization over 5-fold cross-validation. The authors evaluate models on an 80/20 split of GSE144434, a sorted $\text{CD4}^+\text{CD45RA}^-$ T-cell scRNA-seq dataset (GSE150132, "unseen dataset"), and an independent PBMC CITE-seq dataset (GSE164378, downsampled to 80,000 cells, 33,456 T-cell profiles).

While inferring surface CD45RA isoform status from scRNA-seq is a practical problem in T-cell immunology, the study suffers from severe machine-learning evaluation flaws, preprocessing data leakage, and direct numerical/textual contradictions: (1) **the headline 99.96% accuracy in the Abstract is computed on a single-class dataset (GSE150132 sorted $\text{CD45RA}^-$ cells)** where 100% of true labels are negative, meaning a trivial constant classifier predicting $\text{CD45RA}^-$ for every cell achieves 100% accuracy (as admitted in the footnote to Table 4, precision and recall are undefined because there are zero positive instances); (2) on the only genuine two-class external validation dataset (GSE164378, Section 3.3), accuracy drops to **82.31%** (recall 70.73%), with 27.4% to 41.2% misclassification inside the exact biological subsets ($\text{Naive/T}_{\text{CM}}$ Clusters 0 and 7, and $\text{T}_{\text{EM}}/\text{T}_{\text{EMRA}}$ Cluster 4) that CD45RA is needed to distinguish; (3) global `SCTransform` normalization, 3,000-HVG selection, and Otsu thresholding were performed on the entire GSE144434 dataset *before* the 80/20 train-test split (Sections 2.2–2.4), leaking test-set distributional statistics into training; and (4) the Discussion (line 176) directly contradicts the Abstract, Results (line 160), and package implementation by claiming that "LR and SVM (RBF) are not the terminal models incorporated into our Python package," while Table 2 scrambles the hyperparameter values for the MLP models (`Nlayers = 1e-4`, `Nnodes = 0.1`, `eta = 3`, `rho = 105`).

### 2. SPECIFIC CONCLUSIONS AND ASSESSMENT OF SUPPORT

* **The trained RBF-SVM classifier achieves 99.96% accuracy (and the MLP 99.74% accuracy) on an unseen validation dataset:** **[Methodologically Flawed].**  
  The "unseen dataset" highlighted in the Abstract (line 7) and Table 3 is GSE150132, which consists exclusively of flow-sorted $\text{CD4}^+\text{CD45RA}^-$ T cells (zero $\text{CD45RA}^+$ cells). Reporting 99.96% accuracy on a 100%-negative dataset measures only specificity on resting/activated $\text{CD4}^+\text{T}_{\text{EM}}$ cells; a dummy model that always outputs $0$ ($\text{CD45RA}^-$) would achieve 100.00% accuracy. Highlighting 99.96% in the Abstract while omitting the 82.31% accuracy (and 70.73% recall) on the actual two-class external CITE-seq dataset (GSE164378, Section 3.3) is a severe misrepresentation of out-of-distribution generalization.

* **scCD45RA accurately resolves the hard-to-classify $\text{Naive}/\text{T}_{\text{CM}}$ and $\text{T}_{\text{EM}}/\text{T}_{\text{EMRA}}$ T-cell subsets where short-read scRNA-seq lacks CD45RA isoform information:** **[Overstated].**  
  Easy T-cell subsets can already be separated without CD45RA using canonical transcript markers (`CCR7`, `SELL`, `IL7R`, `GZMB`, `PRF1`). The specific immunological utility of CD45RA is to separate $\text{Naive}$ ($\text{CD45RA}^+$) from $\text{T}_{\text{CM}}$ ($\text{CD45RA}^-$) within $\text{CCR7}^+\text{SELL}^+$ cells, and $\text{T}_{\text{EMRA}}$ ($\text{CD45RA}^+$) from $\text{T}_{\text{EM}}$ ($\text{CD45RA}^-$) within $\text{CCR7}^-\text{SELL}^-$ cytotoxic cells. Yet in the held-out test split of GSE144434 (Table 6), RBF-SVM misclassifies **31.13%** of $\text{Naive}/\text{T}_{\text{CM}}$ (C1) and **21.59%** of $\text{T}_{\text{EM}}/\text{T}_{\text{EMRA}}$ (C3) (compared to 2.19% and 0.65% in training—a >15-fold overfitting gap). In the independent two-class CITE-seq dataset GSE164378 (Section 3.3, line 169), misclassification reaches **41.21%** in $\text{CD4}^+\text{Naive}/\text{T}_{\text{CM}}$ (Cluster 0), **27.42%** in $\text{CD8}^+\text{Naive}/\text{T}_{\text{CM}}$ (Cluster 7), and **36.47%** in $\text{CD8}^+\text{T}_{\text{EM}}/\text{T}_{\text{EMRA}}$ (Cluster 4).

* **Training and testing splits on GSE144434 are free of data leakage and overfitting:** **[Methodologically Flawed].**  
  First, in Sections 2.2–2.4, `SCTransform` negative binomial regression, cell-cycle/mitochondrial regression, and Otsu thresholding ($t^*$) were applied to the full GSE144434 matrix prior to the `scikit-learn` 80/20 train-test split, and cells with intermediate CD45RA protein levels inside $[t^* - 0.5, t^* + 0.5]$ were deleted before evaluation, artificially inflating test accuracy by removing boundary cells. Second, the feature selection thresholds ($t_{\text{DE}}$ and $P_{\text{hn}}$) were tuned over the 5-fold CV loop using DEGs and `hnRNPLL` correlations computed on the whole training set outside the CV folds (Section 2.6–2.7), explaining why RBF-SVM 5-fold CV accuracy averaged only 76.21% (line 150) while refitted training accuracy jumped to 99.45% (Table 3).

* **Transcriptional correlation with `hnRNPLL` identifies `HNRNPA2B1` and 1,600 other genes ($P \ge 0.05$) as candidate regulators of CD45 splicing:** **[Fragile].**  
  Line 123 states that `hnRNPLL` correlated with `HNRNPA2B1` "along with other 1600 genes that had a P-value >= .05" (a typo for $\le 0.05$, just as line 115 writes `q-value >= 0.05`). Because `HNRNPA2B1` is a ubiquitous housekeeping spliceosome component co-regulated with proliferation and total mRNA content in activated T cells, bivariate Spearman correlation across bulk T-cell states does not establish a specific role in `PTPRC` (CD45) exon 4/5/6 exclusion without controlling for T-cell activation state.

### 3. CONSTRUCTIVE AND DOABLE SUGGESTIONS FOR IMPROVEMENT

#### 1. Replace the Single-Class GSE150132 Headline Metric in the Abstract with the Two-Class External CITE-Seq Benchmark (GSE164378)
* **WHY:** Reporting 99.96% accuracy in the Abstract on GSE150132—which contains 0% $\text{CD45RA}^+$ cells—misleads readers into believing the classifier has 99.96% balanced classification accuracy on independent datasets, whereas on the two-class external CITE-seq dataset (GSE164378) accuracy is 82.31% and recall is 70.73%.
* **WHAT:** Report the GSE164378 balanced accuracy, AUROC, AUPRC, precision (93.34%), and recall (70.73%) in the Abstract and main tables (Tables 3–5), and relabel the GSE150132 column in Table 3 specifically as `"True Negative Rate on Sorted CD4+CD45RA- (GSE150132)"`.
* **HOW:** Add a column for `GSE164378 (External CITE-seq, n=33,456)` to Tables 3, 4, and 5 for all six classifiers, and revise the Abstract to state both the internal test accuracy (89.94%) and the external two-class CITE-seq accuracy (82.31%).

#### 2. Eliminate Preprocessing Leakage and Evaluate Performance Without Deleting Intermediate $[t^* - 0.5, t^* + 0.5]$ Cells in the Test Set
* **WHY:** Dropping cells with CITE-seq CD45RA levels between $t^* - 0.5$ and $t^* + 0.5$ (Section 2.3) removes the hardest-to-classify biological transition cells ($\text{T}_{\text{Naive}} \leftrightarrow \text{T}_{\text{CM}}$ and $\text{T}_{\text{EM}} \leftrightarrow \text{T}_{\text{EMRA}}$) from the test set. In real scRNA-seq applications, users cannot pre-filter cells by CITE-seq ADT levels before running `scCD45RA`. Furthermore, running `SCTransform` before splitting train and test leaks gene-level dispersion parameters.
* **WHAT:** Split GSE144434 into train (80%) and test (20%) on raw UMI counts first; run `SCTransform`, Otsu thresholding, Monocle 3 DEG calling, and `hnRNPLL` correlations strictly inside each training fold; and evaluate the held-out 20% test set both with and without the $\pm 0.5$ ADT exclusion zone.
* **HOW:** Modify the `scikit-learn` pipeline so that `train_test_split` precedes normalization, keep all test-set T cells binarized at $t^*$ (no $\pm 0.5$ buffer deletion in test), and report the resulting test accuracy, AUROC, and cluster-specific error rates in Tables 3–6.

#### 3. Train Subtype-Conditional Classifiers Within $\text{CCR7}^+\text{SELL}^+$ and $\text{CCR7}^-\text{SELL}^-$ T-Cell Strata
* **WHY:** A global classifier trained across all T cells learns general activation/cytotoxicity genes (`CD28`, `IL7R`, `CD40LG`, `CTLA4`, `TBX21`, `IL2RB`) that separate bulk Naive cells from bulk Effector Memory cells, but fails when asked to distinguish $\text{CD45RA}^+$ $\text{T}_{\text{EMRA}}$ from $\text{CD45RA}^-$ $\text{T}_{\text{EM}}$ (where both are $\text{CCR7}^-\text{GZMB}^+$) or $\text{CD45RA}^+$ Naive from $\text{CD45RA}^-$ $\text{T}_{\text{CM}}$ (where both are $\text{CCR7}^+\text{IL7R}^+$), yielding 27%–41% error rates in Clusters 0, 4, and 7 of GSE164378.
* **WHAT:** Train two specialized second-stage classifiers: one specifically contrasting $\text{Naive}$ ($\text{CD45RA}^+$) vs. $\text{T}_{\text{CM}}$ ($\text{CD45RA}^-$) within $\text{CCR7}^+\text{SELL}^+$ cells, and a second contrasting $\text{T}_{\text{EMRA}}$ ($\text{CD45RA}^+$) vs. $\text{T}_{\text{EM}}$ ($\text{CD45RA}^-$) within $\text{CCR7}^-\text{SELL}^-$ cells.
* **HOW:** Stratify the CITE-seq training data by `CCR7`/`SELL` expression (or Leiden cluster phenotype), compute DEGs between $\text{CD45RA}^+$ and $\text{CD45RA}^-$ *within* each stratum, and route query cells to the corresponding stratum classifier.

#### 4. Technical, Mathematical, and Editorial Cleanup
* **WHY:** The manuscript contains transposed table entries, reversed inequality signs, missing equations, and a direct contradiction regarding which model is deployed in the software package.
* **WHAT & HOW:**
  * **Table 2 (lines 211–214):** The hyperparameter values for both MLP rows are completely scrambled with their variable names: `Nlayers = 1e-4, Nnodes = 0.1, η = 3, ρ = 105` and `Nlayers = 2.262e-4, Nnodes = 0.1, η = 1, ρ = 87`. Clearly, learning rate $\eta \in \{10^{-4}, 2.262 \times 10^{-4}\}$, dropout rate $\rho = 0.1$, number of layers $N_{\text{layers}} \in \{3, 1\}$, and number of nodes $N_{\text{nodes}} \in \{105, 87\}$ were shifted across columns. Fix the variable assignments in Table 2.
  * **Section 4 Discussion (line 176) vs. Abstract (line 7) & Results (line 160):** Line 7 and line 160 state `"Based on the overall performance, we chose the SVM with an RBF kernel as the model implemented in our Python package scCD45RA."` Yet line 176 states `"it is crucial to highlight that LR and SVM (RBF) are not the terminal models incorporated into our Python package"`. Reconcile this direct contradiction so the text accurately states which model `scCD45RA` actually runs.
  * **Lines 115 and 123:** Correct the reversed significance inequalities `q-value ≥ 0.05` (should be `q-value ≤ 0.05` or `< 0.05`) and `P-value > = .05` (should be `P-value < 0.05`).
  * **Lines 49, 85, 91, 97:** Remove the stray question mark and broken citation tokens (`"...experimental conditions? DEG analysis in Monocle 3 Mon involves..."` and `"Bayesian optimization in Python Nog (Nogueira 2014)"`).
  * **Section 2.5–2.6 (lines 51–75):** Ensure the display equations for the quasi-Poisson GLM, variance function, likelihood ratio statistic $D$, and $\log_2 \text{FC}$ render properly in the text.
